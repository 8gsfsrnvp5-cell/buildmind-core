# PR18 — ручная проверка на реальных документах

Реальных PDF/XLSX в репозитории нет, и фиктивные документы для проверки
не создаются. Сквозную проверку выполняет инженер на своих файлах по этому
списку. Автоматические тесты проверяют ту же логику на тестовых структурах.

## Подготовка

1. Открыть BuildMind через локальный сервер (например, `python -m http.server`
   в папке проекта) — PDF.js не работает при открытии `index.html` как файла.
2. Открыть DevTools → Console, включить показ ошибок.
3. При необходимости начать с «Нового чистого проекта» (окно «Проект»).

## 1. PDF (ВОР или ГПР)

| Шаг | Ожидаемый результат | Итог |
|---|---|---|
| «Документы» → загрузить PDF, указать роль документа | Файл в списке, роль сохранена | |
| «Анализировать комплект» | Анализ завершён или показана причина блокировки | |
| «Работы и ГПР» → таблица ВОР/ГПР | В столбце «Источник» — имя файла и `стр. N` | |
| Сверить 3–5 строк с исходными страницами | Значения совпадают с PDF | |
| Строка без количества или даты | Показано «—», не `0`; статус «Не найдено» | |
| Строка, где страница не определена | Нет «стр. 0»; статус «Требует проверки» | |
| Скан с плохим качеством | Карточка «Не прочитано» с номерами страниц | |

## 2. Excel (ВОР или ГПР)

| Шаг | Ожидаемый результат | Итог |
|---|---|---|
| Загрузить XLSX/XLS/CSV, указать роль | Файл в списке | |
| Анализ комплекта | Строки появились в таблице | |
| Столбец «Источник» | Имя файла, `лист …`, `строка …` | |
| Пустая ячейка количества | «—», статус «Не найдено», не `0` | |

## 3. Сверка ВОР ↔ ГПР

| Шаг | Ожидаемый результат | Итог |
|---|---|---|
| ВОР и ГПР с одной работой и разным количеством | Статус «Конфликт источников», карточка показывает оба значения и оба источника | |
| «Выбрать указанный источник» → ГПР | Значение ГПР подтверждено, история содержит старое и новое значение | |

## 4. Спорные моменты и ручное подтверждение

| Шаг | Ожидаемый результат | Итог |
|---|---|---|
| Решение без роли / ФИО / основания | Отказ с понятным сообщением | |
| «Ввести исправленное значение» без документа | Отказ: нужен документ или фото | |
| Исправление с ролью, ФИО, основанием, документом | Статус «Изменено вручную», история: дата, пользователь, роль, старое → новое, основание | |
| Повторное изменение того же значения | История дополнена, первая запись сохранена | |
| «Проверить» у бесспорной строки → «Подтвердить значение из источника» | Статус строки «Подтверждено» после подтверждения всех её значений | |
| Обновить страницу | Решения и история сохранились | |
| «Отклонить вывод» у материала | Кнопка «В контроль снабжения» недоступна | |
| Материал без единицы или источника → «В контроль снабжения» | Перенос заблокирован, единица «шт» не подставляется | |

- [ ] У каждого значения указан файл и страница (PDF) или лист и строка (Excel).
